## 孤儿检查（每轮交付前）

- [ ] 没有"无来源的组件"（每个组件都能回追到 Req ID）
- [ ] 没有"无组件的需求"（每条采用中的需求都有着落页面）
- [ ] 没有"无验收的需求"
- [ ] 没有"无角色的需求"（每条采用需求都能说明由谁完成、在哪个工作台完成）
- [ ] 没有“第二真源”（canonical、usage、snapshot 和 presentation owner 已拆清）
- [ ] 没有“错主语反馈”（用户回执、系统结果、AI 回应和短 Echo 的 owner 可追踪）
