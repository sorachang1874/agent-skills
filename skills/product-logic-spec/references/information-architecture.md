# 信息架构（IA）

> 信息架构层的产物：IA Thesis + App Map + Navigation Role Matrix。回答"什么放在哪里、入口以什么身份出现"。

## 1. 组织原则（先选一个，并声明理由）

| 原则 | 结构 | 适用 |
|------|------|------|
| task-first | 按用户任务组织 | 操作工具型页面（如课后功能入口） |
| object-first | 按业务对象组织（课程/作品/线索） | 内容型目录（课程 tab、作品 tab、后台列表） |
| lifecycle | 按生命周期/阶段组织（草稿→启用） | 流水线、状态机主导的页面 |
| audience | 按角色组织 | 多角色平台 |
| frequency | 按使用频率组织 | 高频快捷入口 |

**纪律**：同一导航层级**不混用**组织原则；混用时必须有声明的例外与理由（例：学生端顶层 = object-first，唯一天然例外是「工作台」= task-first 的课后功能入口，因为它不是内容对象而是功能起点）。

### 1.1 先分工作台，再分对象

多角色 SaaS / 后台先用 **audience + job** 划分工作台，再在每个工作台内部选 object-first、task-first 或 lifecycle。角色工作台边界见 [role-capability-and-surface.md](role-capability-and-surface.md)。

领域对象是真源，不天然是导航。`FieldDefinition`、`Binding`、`PolicyVersion`、`Release` 可以是必要系统对象，但若目标角色只需要表达“跨课延续”“卡住时怎么帮助孩子”“提交审核”，这些对象应由意图层自动生成、只读解释或转专家工作台。

**唯一对象家园 ≠ 唯一 UI 表达**：同一个底层对象可以有教师意图视图、审核摘要和治理详情；它们共享真源，但不共享默认编辑复杂度。

## 2. IA Thesis（一段声明，放在每个 IA 文档开头）

模板：
> {产品/端}的信息以 **{主组织原则}** 组织：{一句话结构}。{例外及理由}。全局导航最多 {N} 个入口：{列表}。{对象}的详情与动作归属 {位置}；{派生视图}不单独成页，作为 {位置} 的 {形态}。

多角色产品先补一句：

> 本工作台主要服务 {角色} 的 {Top task}；{其他角色} 通过 {只读/审核/专家工作台} 使用同一底层对象，不共享默认编辑面。

## 3. App Map（应用地图）

只画**页面/内容节点与归属**，不画按钮：

```
学生端
├── 工作台（课后功能入口）
│   └── 视频创作旅程（→ 课后原型）
├── 课程 tab
│   ├── 系列层：课程系列 → 系列详情
│   └── 课程层：课 1…N → 课程体验（→ 课内原型）
├── 作品 tab
│   └── 分类页签：全部 / 图片 / 短视频 / 长视频
└── 我的 tab
    ├── 账号卡
    ├── 进度看板（派生，只读）
    └── 徽章架
```

## 4. Navigation Role Matrix（导航角色矩阵）

每个入口登记角色，**重复路径必须有明确收益**：

| 入口 | 目标 | 角色（Global/Local/Contextual/Shortcut/Action） | 出现位置 | 重复路径理由 |
|------|------|------|----------|--------------|
| 底部 tab：工作台/课程/作品/我的 | 四大内容区 | **Global** | 全部课外页面底部 | — |
| 系列卡 | 系列详情 | **Local**（课程 tab 内） | 课程 tab | — |
| 作品分类页签 | 类型过滤 | **Local**（作品 tab 内） | 作品 tab | — |
| 看作品 › | 作品 tab | **Contextual**（课程语境下） | 课程卡 | 从课程上下文直达其产物，省一次 tab 切换+查找 |
| 再玩一次 / 接着玩 | 课程体验 | **Action**（对象动作，不是导航） | 课程卡 | — |
| hero：视频创作旅程 | 课后功能 | **Global function entry** | 工作台 | 工作台的本体职责 |

反重复规则（从实战多轮返工固化）：
1. 同一内容只允许一个"家"；别处出现只能是 **Contextual 链接**且必须声明收益；
2. 入口的"角色"必须单一：不能既像全局导航、又像内容摘要、又像页内锚点（旧"四入口"的死因）；
3. 派生视图（进度/统计）不做独立导航项，作为只读看板放进其宿主页。
4. 角色不可理解的对象不因“有权限”进入其 Global/Local 导航；隐藏按钮不能补救错误的页面归属。
5. 导航评审同时检查 Role–Surface Access Matrix：页面的主要角色必须唯一，专家入口必须明确退出与返回语境。

## 5. 命名与分类

- 命名用用户侧语言（孩子说"我的作品"，不说"产出物"；后台说"线索库"，不说"导入素材管理中心"以外的别名）；
- 同一对象全端同名：Season（系列/季）、Course（课程）、Session（场次）、Artifact（作品）、Clue（线索）；
- 分类页签层级 ≤ 2（tab → 页签），不再下钻。
